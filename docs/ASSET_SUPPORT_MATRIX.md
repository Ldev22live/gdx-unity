# Asset Support Matrix: Desktop and Web, per Shipped File

What the desktop and the Babylon web player do with **every file the editor package ships** (roadmap M2b.7, [TD-101](TECHNICAL_DECISIONS.md)). Report: [reports/m2b-7-asset-support-matrix.md](reports/m2b-7-asset-support-matrix.md).

**Where it is recorded:**
- **Per file:** [`migration/asset-support.tsv`](migration/asset-support.tsv), one row per file. Columns: path, format, licence record, used by (samples, the starter palette, both or neither), desktop status, web status.
- **Summed up:** the table below, by folder.
- **How it is made:** both are generated by `AssetSupportMatrix` (`editor-desktop`, audit package) and kept current by `AssetSupportMatrixTest`. The test fails when either is stale. Refresh them with `GDXUNITY_UPDATE_AUDIT=1 ./gradlew :editor-desktop:test --tests "*AssetSupportMatrixTest"`.

**"Shipped"** means what `editor-desktop/build.gradle` packages: all of `assets/` except `build/` and the editor's own preference files. That includes the raw Kenney downloads at the top of `assets/` and the Kenney model copies in `models/<format> format/`. Whether those stay is the owner's open decision (M2b.5).

**Status words** are those of the [backend support matrix](BACKEND_SUPPORT_MATRIX.md):

| Word | Meaning here |
|---|---|
| **Works** | The backend reads the file for what it is. On the web, a model only when the web tests load it (`engine-babylon/test/modelFiles.test.ts` loads every served model that names no outside file) |
| **Partial** | It runs, with the gap stated (a scene with a component or script the web does not have) |
| **No** | Not read: a source format (FBX, OBJ, DAE, STL), a Java script on the web, or a file the web build is not given |
| **Unchecked** | Given to the web build, but not loaded by a test (models that name outside files, and the files they name) |
| **Not applicable** | Documentation, licence text, archives, and editor-only files (prefabs, thumbnails, previews, records) |

**What the web build is given** is decided by `engine-babylon/scripts/sync-samples.mjs`, mirrored by `AssetSupportMatrix.WEB_RULES`; the test checks the two agree:
- scenes, models, songs, clips, graphs, baked characters, sprites, terrains, materials and textures;
- since M2b.7, the downloaded packs' `Models` folders.

Nothing else reaches the web.
