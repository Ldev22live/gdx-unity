# Third-party assets

The [project manifest](../../assets/licenses/manifest.json) records creators, source URLs, conversion details and SHA-256 for the seven runtime files added in this pass. The [inventory](opengameart-inventory.md) links each source listing and records the local file disposition. CC0 permits redistribution. Creator credit is preserved in the manifest. [CC0 legal text](https://creativecommons.org/publicdomain/zero/1.0/legalcode)

- atornity created Detective Bunny. ForgeRoom exports a subset of the supplied actions and uses the original embedded artwork.
- CDmir and TinyWorlds created Rabbit. ForgeRoom retained the source skin, fur and normal maps and rebuilt their shader links.
- br-n518 created Fox. ForgeRoom applied the source?s mirror and embedded the supplied 1K diffuse and normal maps.
- WeaponGuy created the boulder geometry. Its missing legacy image was omitted. The runtime export embeds Amal Kumar?s existing CC0 [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) base color.
- KillGorack created Hex Paver B. ForgeRoom downsized its diffuse, AO and normal maps. The externally referenced grass is associated with variant C, which was excluded.

Fox Bases requires author attribution under its CC BY 4.0 option and a decision under TD-094 before redistribution in ForgeRoom. Mansedj remains a preserved source outside the runtime project.

## Owner-approved CC BY 3.0 imports

- **Warrior low poly**, by jjmoser. ForgeRoom converted the original Blender mesh to GLB and bound the supplied diffuse and normal maps. It appears as a static courtyard training mannequin. [Source](https://opengameart.org/content/warrior-low-poly)
- **Thin Zombie**, by Rosswet Mobile. ForgeRoom converted the rigged character to GLB with the source texture and six selected actions. The range uses the authored idle action on a decorative observer. [Source](https://opengameart.org/content/thin-zombie-awake-zombie-asset)
- **Horror sci-fi 3d map kit**, by Rosswet Mobile. ForgeRoom imported the room and cover OBJ meshes, rebuilt their material bindings with the supplied textures and exported GLBs for the range. [Source](https://opengameart.org/content/horror-sci-fi-3d-map-kit)
