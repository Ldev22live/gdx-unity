# Asset attribution

The environment material pass uses existing CC0 assets. Their file sizes and SHA-256 values match the project manifest. This pass acquired no new binaries.

- Red Brick 03 by Rob Tuytel. [Poly Haven](https://polyhaven.com/a/red_brick_03)
- Rocky Terrain 02 by Amal Kumar. [Poly Haven](https://polyhaven.com/a/rocky_terrain_02)
- Wood Floor Deck by Dimitrios Savva. [Poly Haven](https://polyhaven.com/a/wood_floor_deck)

The [license manifest](asset-license-manifest.json) records the reused files and their scene assignments. The [runtime manifest](../../assets/licenses/manifest.json) remains the project-wide source of provenance. [CC0 license](https://creativecommons.org/publicdomain/zero/1.0/)

For the later OpenGameArt imports, see [Third-party assets](THIRD_PARTY_ASSETS.md).
