### 3.2 Evidence Supporting Each Rule
1. **`**/build/`**:
   - *Rationale:* The original LibGDX `.gitignore` had root-anchored rules (`/build/`, `/core/build/`, `/lwjgl3/build/`). Newer active multi-projects (`engine-core`, `engine-scene`, `engine-render`, `engine-desktop`, `editor-core`, `editor-desktop`) generate subproject `build/` directories (classes, libs, reports).
   - *Verification:* Verified that `**/build/` ignores intermediate outputs such as `editor-core/build/libs/*.jar` without ignoring any source files.
2. **`workspace_layout.json`**:
   - *Rationale:* Generated automatically by `WorkspaceLayoutSerializer.java` inside `EditorApplication.java` to cache window split-pane ratios. It is developer-specific local state.
   - *Verification:* Exists in root as `{}`; now ignored by git.
3. **`editor_theme.json`**:
   - *Rationale:* Generated automatically by `EditorThemeManager.java` when switching between light and dark themes. It represents local UI preferences rather than repository model code.
   - *Verification:* Verified tested in `EditorThemeSystemTest`.
4. **`scene_backup.json`**:
   - *Rationale:* Generated by `EditorApplication.java` (Line 258) when invoking `File -> Save Scene` as an editor backup cache. Should not pollute source control.
5. **`.vscode/` (Deliberately NOT ignored in this diff)**:
   - *Analysis:* Contains `.vscode/settings.json` configuring `"java.configuration.updateBuildConfiguration": "interactive"`. It contains no machine-specific credentials or absolute paths. Leaving it untracked allows the user to decide whether to commit it as shared IDE configuration or add it to local ignores.
