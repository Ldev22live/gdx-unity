### What the inventory shows

- **8 actions have no route on screen today:** Shadows, the three Lighting Quality levels, Toggle Dark/Light Theme, About, Enter Sculpt Mode and Exit Sculpt Mode. The last two are covered by the Sculpt toggle (button and F4). The first five are real features that a person currently cannot use, because the Window and Help menus are not shown. They are planned for a Settings menu in the header; until R1b builds it, they stay hidden, and the test pins exactly these eight so that no ninth can join them unnoticed. **Update (M1b.2 stage 1, 2026-11-14):** the header's Settings dropdown now holds the first six, and the File dropdown became the header's Project dropdown; the table above is regenerated and shows only the two sculpt entries as hidden.
- **Only the File and Create dropdowns are shown** (at M1b.1; since stage 1, Project, Settings and Create). Every Edit, Tools, Window and Help action is reached through a button, a shortcut, the Outliner's context menu or the sculpt strip, or not at all (above).
- **Several actions have two routes that do the same thing** (top bar buttons and menu items; the AI Assistant toolbar button and its Window action). The World-first layout removes the duplicates by giving each action one home; the shortcuts stay.

## Supported genre and game-mode combinations today

There is **no genre system** in the editor or the runtimes yet (roadmap R3b, milestones M3b.1 to M3b.7). The only selector is the scene's authoring game mode (2D, 2.5D, 3D), which changes the view and which components are offered; it does not supply any gameplay. So by Appendix F5's rule, **no genre and mode combination is playable from a selector today**. Games exist only as samples with their own scripts:

## Risks

| Risk | Why it matters | Mitigation |
|---|---|---|
| Hiding a feature while moving it | M1.5 found five File actions with no route; this audit finds eight more | `ActionInventoryTest` pins every action's home and the hidden set; a move that drops a route fails it |
| Two "game mode" meanings | Authoring mode (today's 2D/2.5D/3D buttons) and Appendix E's play-time Game Mode in the footer | Owner decision 11 before M1b.3 |
| Customize as a second editor | Appendix E2 warns it must be a gateway, not a duplicate | Customize only switches workspace; each workspace keeps its existing panel |
| The default screen loses expert speed | Outliner and Details are used constantly today | Keep them as collapsible panels with shortcuts; measure in the M1b.5 usability test |
| Work ahead of decisions | Appendix E is a proposal | Nothing in M1b.2 onward starts before decision 16 |
| Graphics settings stay hidden | Shadows and lighting quality cannot be changed today | A Settings menu early in M1b.2, or an interim route if the owner wants one sooner |
