Required by `docs/design-doc.md.txt` §10.3. Status words are defined in `AGENTS.md` §9:
**Implemented** = code + automated tests · **Integrated** = reachable by a user in the editor/runtime ·
**Validated** = integrated and checked in the running app (needs a dated report).

**Last reconciled: 2026-11-14 (roadmap milestone M0.5)** against the working tree on `phase-12-3d-foundation` @ `d896331` plus a large amount of uncommitted work. A full run from scratch (`./gradlew cleanTest test --continue`) exited 0: **1,869 tests, 0 failures, 0 errors, 1 skipped** across 23 modules, and the web player's `npm test` passed **478** tests (counts in [reports/m0-4-acceptance-project-report.md](reports/m0-4-acceptance-project-report.md), [reports/m0-1-test-baseline-report.md](reports/m0-1-test-baseline-report.md)). The one skip is `GameExporterTest.shouldKeepTheLauncherExecutableOnALinuxImage`, which needs POSIX file permissions and so only runs on Linux or macOS.

**What this date does and does not support.** Every row's status word is as its own entry last said. M0.5 did **not** re-verify each row. A passing full run supports "Implemented" (code and tests exist and pass today) and says nothing about "Integrated" or "Validated"; rows that say "Not validated" or "Manually Not Verified" are still waiting for a person. Rows dated before 2026-11-14 are as dated. Older "complete" wording in reports from before 2026-10-29 is not evidence (AGENTS.md §0).
